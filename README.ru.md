# Weak Cards Quiz

Weak Cards Quiz — браузерное приложение для тренировки сложных вопросов ирландского теоретического экзамена по вождению. Оно предназначено для русскоязычных учеников, которые сдают официальный экзамен на английском языке.

Приложение дополняет официальное приложение для подготовки к теоретическому экзамену. Его главная задача — собрать вопросы, в которых вы раз за разом ошибаетесь, и тренировать их отдельно.

## Как работает приложение

- Тесты состоят из батчей размера, заданного на странице «Тест» (Quiz) (по умолчанию 10). В тесте никогда не бывает больше карточек, чем у вас есть.
- Приложение само выбирает этап при каждом запуске теста; переключить этап вручную нельзя. Пока остаются непоказанные карточки, идёт этап 1. Когда все карточки просмотрены, следующий тест начинает этап 2.
- **Этап 1:** тест показывает карточки, которые ещё ни разу не показывались, в порядке их хранения.
- **Этап 2:** тест случайно выбирает уже показанные карточки, в которых была ошибка и которые ещё не достигли порога запоминания. Правильный ответ увеличивает счётчик верных ответов подряд, неправильный сбрасывает его до нуля.
- Карточка, на которую при первом показе ответили правильно, сразу считается выученной. Карточка с ошибкой становится выученной, когда набирает заданное число верных ответов подряд.
- Порог запоминания задаётся в настройках (Settings). По умолчанию он равен 3, и его можно изменить в любой момент.
- Плитки статистики меняются в зависимости от этапа. На этапе 1 плитка **Показано** (**Shown**) показывает, сколько карточек уже просмотрено, а **Карточек с ошибками** (**Cards with errors**) — сколько карточек потребуют повторения на этапе 2. На этапе 2 плитка **Изучено** (**Learned**) показывает выученные карточки, а **Карточек с ошибками** (**Cards with errors**) — оставшийся набор для повторения.
- Плитка **Карточек с ошибками** (**Cards with errors**) при нажатии фильтрует список карточек, а не запускает тест. Повторное нажатие на активную плитку снимает фильтр. Плитки **Показано** (**Shown**) и **Изучено** (**Learned**) не нажимаются. Тест запускается только кнопкой **Начать тест** (**Start quiz**) на странице «Тест» (Quiz).
- На этапе 2 каждая карточка в тесте показывает текущее число верных ответов подряд (или **Выучено** (**Learned**)) и сколько раз она была показана. После последней карточки батча приложение возвращается к списку карточек.
- В списке карточек правильный вариант всегда подсвечен зелёным. Если ваш последний ответ на карточку был неправильным, выбранный вами вариант подсвечивается красным. Карточки с неправильным последним ответом идут первыми, карточки без единой ошибки — последними, а внутри каждой группы карточки отсортированы по числу показов.
- Варианты ответа перемешиваются при каждом запуске теста, поэтому при повторном показе той же карточки правильный ответ может оказаться на другой позиции.
- Любую карточку можно переключить между английским и русским языком, чтобы полностью понять вопрос и варианты ответа.

## Рекомендуемый порядок работы

1. Пройдите вопросы в официальном ирландском приложении для подготовки к теоретическому экзамену.
2. Откройте в нём раздел «Ранее отвеченные неверно» (`Previously answered incorrectly`).
3. Сделайте скриншоты вопросов, на которые вы ответили неправильно.
4. Отправьте ИИ-ассистенту до 15 скриншотов за раз вместе с промптом ниже.
5. Скачайте JSON-файл, который создаст ИИ, или сохраните его ответ как файл `.json`.
6. Откройте Weak Cards Quiz и нажмите «Загрузить JSON-файл» (`Import JSON`).
7. Выберите один или несколько созданных JSON-файлов, затем откройте страницу «Тест» (Quiz) и нажмите «Начать тест» (`Start quiz`).
8. Сначала тест проходит по всем импортированным карточкам, затем повторяет карточки с ошибками, пока они не достигнут порога запоминания, указанного в настройках.

## Импорт и экспорт карточек

Приложение принимает JSON-массив верхнего уровня, состоящий из объектов карточек. Если выбрано несколько файлов, корректные карточки импортируются, даже если другой файл или другая карточка содержат ошибки. Некорректные карточки пропускаются, и о них выводится сообщение.

Дубликаты определяются автоматически. Новая карточка пропускается, если её английский вопрос и английский текст правильного ответа совпадают с уже существующей карточкой или с другой карточкой из того же импорта. При сравнении регистр букв и пробелы не учитываются. Статистика существующих карточек при импорте новых сохраняется. Импортированные карточки сохраняют `stats`, записанные в файле, если они там есть.

Кнопка «Экспортировать JSON» (`Export JSON`) скачивает все сохранённые карточки в файл `weak-cards-quiz.json`. Экспортированный файл содержит содержимое карточек и накопленную статистику `stats`, но не внутреннее поле `id`. Так можно сделать резервную копию карточек и перенести их вместе со статистикой на другое устройство.

## Локальное хранение данных

У приложения нет бэкенда. Карточки, статистика тестов, выбранный размер батча, порог запоминания и стартовая страница хранятся в `localStorage` браузера и сохраняются после перезапуска браузера и компьютера. Текущий тест хранится только в памяти.

При первом запуске опубликованного приложения, когда сохранённых карточек ещё нет, автоматически загружается набор тестовых карточек. Когда список карточек пуст, кнопка «Загрузить тестовые карточки» (`Load sample cards`) загружает их снова; в противном случае та же кнопка после подтверждения удаляет все карточки. «Обнулить статистику» (`Reset statistics`) очищает статистику всех карточек.

Язык интерфейса тоже хранится в `localStorage`. По умолчанию выбран английский, русский можно включить в настройках. В настройках также можно выбрать страницу, которая открывается при запуске: «Все карточки» (All cards), «Тест» (Quiz) или «О приложении» (About, по умолчанию). Язык интерфейса не зависит от переключателя английского/русского языка внутри каждой карточки.

Эти данные доступны только в браузере на том устройстве, где они были созданы. Чтобы перенести карточки и накопленную статистику на другое устройство, экспортируйте карточки в JSON и загрузите этот файл на другом устройстве.

## Формат JSON

Каждая карточка должна содержать английскую и русскую версии с одинаковыми ID вариантов, а также `correctOptionId`:

```json
[
  {
    "en": {
      "question": "What does this sign mean?",
      "options": {
        "opt1": "No overtaking",
        "opt2": "Parking is allowed",
        "opt3": "Road works ahead"
      }
    },
    "ru": {
      "question": "Что означает этот знак?",
      "options": {
        "opt1": "Обгон запрещён",
        "opt2": "Парковка разрешена",
        "opt3": "Дорожные работы впереди"
      }
    },
    "correctOptionId": "opt1"
  }
]
```

Во время тренировки приложение добавляет или обновляет внутренние данные `stats` (`timesShown`, `timesCorrect`, `lastSelectedOptionId`). Карточка отклоняется при импорте, если в `en` и `ru` нет непустого `question` и непустого объекта `options` или если `correctOptionId` отсутствует в каком-либо из списков вариантов. ID вариантов должны совпадать в обеих языковых версиях: тест берёт ID вариантов из `en` и ищет русский текст по тем же ID.

## Промпт для создания карточек по скриншотам

Страница «О приложении» (About) показывает этот промпт с кнопкой «Копировать» (`Copy`) (на русском, если выбран русский язык интерфейса). Прикладывайте не больше 15 скриншотов к одному запросу:

```text
Analyze the provided screenshots from the Driving Theory Test app (Ireland, RSA).

Create and provide a ready-to-download data.json file containing the analysis results.

Data structure in the JSON file:

- "correctOptionId": ID of the correct answer ("opt1", "opt2", "opt3", "opt4", etc.).
- "en": an object with the question and answer options in English (as shown in the screenshot).
- "ru": an object with a high-quality Russian translation of the question and answer options.

File structure template:
[
  {
    "correctOptionId": "opt1",
    "en": {
      "question": "English question text?",
      "options": {
        "opt1": "Option 1",
        "opt2": "Option 2",
        "opt3": "Option 3"
      }
    },
    "ru": {
      "question": "Текст вопроса на русском?",
      "options": {
        "opt1": "Вариант 1",
        "opt2": "Вариант 2",
        "opt3": "Вариант 3"
      }
    }
  }
]
```

Когда ИИ вернёт JSON-файл, импортируйте его в приложение и запустите тест.
